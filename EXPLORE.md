# Explore & Data

FAILED Calculator 1.6 extends the Mathematical Workbench with function exploration,
numerical methods, statistics, and multiple plots.

## Value tables

```text
table(sin(x),x,-3,3,0.5)
```

produces an interactive-style scrollable table of `x` and `f(x)` values.

## Multiple curves

```text
multiplot([sin(x),cos(x),exp(-x^2)],x,-6,6)
```

draws several functions on one result canvas. Up to eight curves can be displayed.

## Numerical solving

```text
nsolve(cos(x)-x,x,1)
```

uses Newton iteration with a derivative generated by the symbolic engine.

## Interval minimization

```text
minimize(x^4-3x^2+2,x,-3,3)
```

uses a golden-section search on the requested interval.

## Descriptive statistics

```text
mean([1,2,3,4])
median([1,2,3,4])
variance([1,2,3,4])
stdev([1,2,3,4])
quantile([1,2,3,4],0.75)
summary([1,2,3,4,5,10])
```

`summary` returns count, min, quartiles, median, mean, max, variance, and standard deviation.

## Linear regression

```text
linreg([1,2,3,4],[2,4.1,5.9,8.2])
```

returns a fitted line and R².

These features live in `js/workbench/` and do not replace the original dementia-aware
engine for ordinary calculator expressions.
