# FAILED Calculator — dementia build

Статический шуточный калькулятор, который:

- начинает каждый новый **browser session** без знаний;
- при первой встрече с `+`, `-`, `×`, `÷`, `%`, `^` реагирует как на открытие;
- для небольших целых чисел буквально заполняет таблицу результатов;
- крупные числа и дробные случаи запоминает отдельно;
- показывает свою текущую таблицу во вкладке **«Таблицы памяти»**;
- через случайный промежуток времени переживает полный провал памяти;
- после деменции снова удивляется уже знакомым операциям;
- хранит всё только в `sessionStorage`, поэтому никакой backend не нужен.

## Запуск локально

Можно просто открыть `index.html`, но надёжнее:

```bash
python -m http.server 8000
```

и открыть `http://localhost:8000`.

## GitHub Pages

Для user-site репозиторий обычно называется:

```text
USERNAME.github.io
```

Положи файлы в корень репозитория, затем:

**Settings → Pages → Deploy from a branch → main / root**

Сайт станет доступен по:

```text
https://USERNAME.github.io/
```
