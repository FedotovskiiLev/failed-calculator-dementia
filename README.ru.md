# FAILED Calculator — dementia build

[English](README.md) · [**Русский**](README.ru.md)

> Калькулятор, который не *знает* математику.  
> Он открывает её, строит воспоминания, становится образованным — а затем постепенно всё забывает.

**Демо:** после публикации сюда можно добавить ссылку на GitHub Pages.

## Что это такое?

FAILED Calculator — намеренно переусложнённый статический веб-эксперимент.

Новый браузерный сеанс начинается с полностью пустого математического мозга. Пользователь не выбирает операцию из заранее показанного списка — он просто пишет выражение:

```text
2 + 2
7 * 8
2 + 5i
sqrt(-1)
sin(pi/2)
(2+3i)*(4-i)
12!
```

Встретив неизвестное понятие, калькулятор не выдаёт сухое «не знаю». Он останавливается, удивляется, пытается осмыслить увиденное и создаёт новое внутреннее воспоминание.

Для небольших целых чисел бинарные операции хранятся буквально в виде таблиц результатов. Комплексные, дробные, функциональные и другие необычные случаи сохраняются как эпизодические воспоминания.

А потом начинается деменция.

## Как работает деменция

Забывание происходит постепенно, а не одним полным сбросом по таймеру.

Во время приступа калькулятор может:

- потерять часть уверенности в математическом понятии;
- повредить случайные ячейки таблицы сложения, умножения и т. п.;
- полностью забыть отдельные ячейки;
- потерять эпизодические примеры;
- со временем забыть сам смысл операции.

Во вкладке **«Память»** деградация видна буквально: повреждённые ячейки тускнеют, а забытые превращаются в дырки.

Если калькулятор снова встречает наполовину забытое понятие, он может смутно его узнать и восстановить. Если понятие уничтожено полностью — он открывает его заново и снова удивляется.

**Журнал наблюдателя** находится как бы снаружи мозга, поэтому не стирается вместе с математическими знаниями и позволяет наблюдать весь цикл обучения и распада.

## Поддерживаемый синтаксис

Парсер специально похож на обычный математический калькулятор и **не использует** JavaScript `eval()`.

Поддерживаются:

```text
+  -  *  /  %  ^  !
( )
неявное умножение: 2i, 2pi, 2(3+4)
pi
e
i
sqrt(x)
abs(x)
sin(x)
cos(x)
tan(x)
ln(x)
log(x)
exp(x)
```

Комплексная арифметика поддерживается. Запись `2+5i` не считается ошибкой: при первой встрече с `i` калькулятор на несколько секунд переживает кризис картины мира, а затем продолжает вычисление.

## Приватность и состояние

Backend отсутствует.

Мозг хранится в браузерном `sessionStorage`, поэтому:

- каждый новый посетитель начинает с пустого калькулятора;
- обновление страницы в той же вкладке сохраняет текущий мозг;
- разные посетители не делятся воспоминаниями;
- для публикации достаточно GitHub Pages.

## Локальный запуск

Можно просто открыть `index.html`, либо запустить маленький статический сервер:

```bash
python -m http.server 8000
```

После этого открыть:

```text
http://localhost:8000
```

## Публикация через GitHub Pages

Создай репозиторий, например:

```text
failed-calculator
```

Загрузи файлы проекта прямо в корень репозитория.

После этого:

```text
Settings → Pages → Deploy from a branch → main → / (root)
```

Для репозитория `failed-calculator` сайт обычно будет находиться по адресу:

```text
https://ТВОЙ_USERNAME.github.io/failed-calculator/
```

## Зачем?

Потому что реализовать `2 + 2` через постепенно разрушающуюся синтетическую память очевидно правильнее, чем просто использовать `+`.
